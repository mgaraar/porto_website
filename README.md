# Magara Reyvandika — Portfolio

Portofolio pribadi untuk menampilkan profil, proyek, dan sertifikat.

## Fitur

- Hero section dengan nama dan peran
- About — latar belakang pendidikan dan pengalaman
- Projects — daftar proyek dengan filter berdasarkan tag
- Certificates — sertifikat dengan popup gambar dan link verifikasi
- Terminal interaktif — mencoba perintah seperti `help`, `whoami`, `projects`, `path`, `goal`, `contact`
- Path / timeline — perjalanan dari SMK, internship, kuliah, sampai tujuan karir
- Contact — email, GitHub, LinkedIn
- Light / dark theme toggle
- Responsive layout untuk mobile

## Tech Stack

- HTML5
- CSS3 (vanilla, tanpa framework)
- JavaScript (vanilla, tanpa framework)

## Struktur Folder

```
porto_website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
    ├── sertifikat-dicoding-javascript.png
    └── sertifikat-dicoding-web.png
```

## Cara Menjalankan

1. Clone repository ini
2. Buka `index.html` di browser
3. Tidak membutuhkan build tools atau server khusus

## Konten Data

Data proyek, sertifikat, kontak, dan timeline dapat diedit di:

- `js/main.js` — bagian `PROJECTS`, `CERTS`, `PATH`, `CONTACT`
